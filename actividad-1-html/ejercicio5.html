¿🌐Como funciona una pagina web en internet?

Una pagina web funciona gracias a varios elementos
que trabajan juntos para que puedas verlas desde tu celular o computadora.

🧠Elementos principales

  • Dominio: es el nombre de la pagina (ej:google.com)
  • Hosting: es donde se guarda la pagina
  • Servidor: es la computadora que entrega la pagina
  • Navegador: es el programa que la muestra (Chrome, Firefox, etc)
💡Conclusiones

Sin el dominio, hosting y servidores, las paginas web no podran existir.
Todos estos elementos trabajan juntos para que internet funcione.
